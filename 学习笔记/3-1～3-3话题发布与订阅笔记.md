# 3-1 ~ 3-3 话题（Topic）发布与订阅

## 1. 话题通信模型

话题是 ROS 2 里最常用的通信方式，**一对多、单向、异步**：

```
发布者 Publisher ──► 话题 /turtle1/cmd_vel ──► 订阅者 Subscriber
  (turtle_circle)        (消息类型 Twist)         (turtlesim 仿真器)
```

要点：

| 概念 | 说明 |
|------|------|
| 话题名 | 字符串，如 `/turtle1/cmd_vel`。**发布和订阅必须完全一致**才算接通 |
| 消息类型 | 如 `geometry_msgs/msg/Twist`。两边类型也必须一致 |
| 队列长度 | `create_publisher` / `create_subscription` 的第二个参数，缓存来不及处理的消息 |
| 异步 | 发布者发完就走，不关心有没有人订阅；订阅者用**回调函数**被动接收 |

**和服务的区别**：话题是"广播、不等回复"，服务是"请求-应答、要等结果"。传感器数据、速度指令这类**周期性、高频**的都用话题。

## 2. 发布者：Publisher + 定时器

核心就两步：建发布者、建定时器，在定时器回调里发消息。

```cpp
#include "rclcpp/rclcpp.hpp"
#include "geometry_msgs/msg/twist.hpp"
#include <chrono>
using namespace std::chrono_literals;   // 让下面的 1000ms 能用

class TurtleCircle : public rclcpp::Node
{
public:
    explicit TurtleCircle(const std::string& node_name) : Node(node_name)
    {
        // ① 创建发布者：<消息类型>("话题名", 队列长度)
        publisher_ = this->create_publisher<geometry_msgs::msg::Twist>("/turtle1/cmd_vel", 10);

        // ② 创建定时器：每 1000ms 调一次回调
        timer_ = this->create_wall_timer(1000ms, std::bind(&TurtleCircle::timer_callback, this));
    }

private:
    void timer_callback()
    {
        auto msg = geometry_msgs::msg::Twist();
        msg.linear.x = 1.0;    // 线速度
        msg.angular.z = 0.5;   // 角速度
        publisher_->publish(msg);
    }

    rclcpp::TimerBase::SharedPtr timer_;
    rclcpp::Publisher<geometry_msgs::msg::Twist>::SharedPtr publisher_;
};

int main(int argc, char * argv[])
{
    rclcpp::init(argc, argv);
    auto node = std::make_shared<TurtleCircle>("turtle_circle");
    rclcpp::spin(node);      // 转起来，回调才会被调用
    rclcpp::shutdown();
    return 0;
}
```

**三个关键点：**

1. **`create_publisher<消息类型>("话题名", 队列长度)`** —— 模板参数写消息类型，`<类型>` 和话题名必须对得上。
2. **消息要先构造再填字段**：`auto msg = geometry_msgs::msg::Twist();`，然后 `msg.linear.x = ...`。C++ 里 `Twist` 默认会把所有字段初始化成 0。
3. **`publish(msg)` 发出去** —— 但如果没有 `rclcpp::spin(node)`，定时器回调根本不会触发，发不出去。

`linear.x` 是**线速度**（前进），`angular.z` 是**角速度**（左正右负）。同时给 1.0 和 0.5 → 走圆弧。

## 3. 订阅者：Subscription + 回调函数

订阅方不主动"读"，而是**注册一个回调**，消息一到就被调用。

```cpp
#include "rclcpp/rclcpp.hpp"
#include "geometry_msgs/msg/twist.hpp"
#include "turtlesim/msg/pose.hpp"
#include <cmath>

class TurtleController : public rclcpp::Node
{
public:
    TurtleController() : Node("turtle_controller")
    {
        velocity_publisher_ = this->create_publisher<geometry_msgs::msg::Twist>("/turtle1/cmd_vel", 10);

        // 订阅：<消息类型>("话题名", 队列长度, 回调函数)
        pose_subscription_ = this->create_subscription<turtlesim::msg::Pose>(
            "/turtle1/pose", 10,
            std::bind(&TurtleController::on_pose_received, this, std::placeholders::_1));
    }

private:
    void on_pose_received(const turtlesim::msg::Pose::SharedPtr pose)
    {
        // 回调参数是"共享指针"，用 -> 访问字段
        double current_x = pose->x;
        double current_y = pose->y;
        // ... 计算并发布速度指令
    }

    rclcpp::Publisher<geometry_msgs::msg::Twist>::SharedPtr velocity_publisher_;
    rclcpp::Subscription<turtlesim::msg::Pose>::SharedPtr pose_subscription_;
};
```

**`std::bind` 这一行长什么样必须背下来：**

```cpp
std::bind(&类名::回调函数名, this, std::placeholders::_1)
//        └── 要绑的函数 ──┘  └自己┘  └── 占位符：第 1 个参数是消息 ──┘
```

- `this` 不能省 —— 否则回调没有对象可依附
- `std::placeholders::_1` 表示"消息从这个口子传进来"，函数有几个参数就写到 `_N`
- 回调**参数类型是 `消息类型::SharedPtr`**（共享指针），所以访问字段用 `->` 而不是 `.`

## 4. 实战：让海龟走到指定坐标

`turtle_control` 是"订阅位置 → 计算 → 发布速度"的闭环，是本节最有价值的模板：

```cpp
void on_pose_received(const turtlesim::msg::Pose::SharedPtr pose)
{
    auto message = geometry_msgs::msg::Twist();
    double distance = std::sqrt(std::pow(target_x_ - pose->x, 2) + std::pow(target_y_ - pose->y, 2));
    double angle = std::atan2(target_y_ - pose->y, target_x_ - pose->x) - pose->theta;

    if (distance > 0.1)                       // 还没到
    {
        if (fabs(angle) > 0.2)                // 朝向不对 → 原地转
            message.angular.z = fabs(angle);
        else                                  // 朝向差不多 → 直行
            message.linear.x = k_ * distance; // 比例控制
    }
    if (message.linear.x > max_speed_)        // 限速
        message.linear.x = max_speed_;

    velocity_publisher_->publish(message);
}
```

**三个可复用的技巧：**

1. **距离用勾股定理**，**朝向偏差用 `atan2(dy, dx) - theta`**。`atan2(y, x)` 返回目标点相对当前位置的方位角，减去当前朝向 `theta` 就是"还需要转多少"。
2. **比例控制（P 控制）**：`速度 = k × 距离`。离得远跑得快，离得近慢下来，自然收敛。`k_` 就是比例系数（这里是 1.0）。
3. **限速**：比例控制会算出很大的速度，必须用 `max_speed_` 截断。

> ⚠️ 教材代码有个小瑕疵：`message.angular.z = fabs(angle)` 取了绝对值，**海龟永远逆时针转**。因为 `angle` 可能落在 ±π 之外，取绝对值后会绕远路。想看更平滑的效果，改成判断符号、同时修正角度到 `[-π, π]`。

## 5. CMakeLists.txt 配置

一个包里有**两个可执行文件**，就是重复写两遍：

```cmake
find_package(ament_cmake REQUIRED)
find_package(rclcpp REQUIRED)
find_package(geometry_msgs REQUIRED)
find_package(turtlesim REQUIRED)          # 用到 turtlesim/msg/Pose 才需要

add_executable(turtle_circle  src/turtle_circle.cpp)
add_executable(turtle_control src/turtle_control.cpp)

ament_target_dependencies(turtle_circle  rclcpp geometry_msgs turtlesim)
ament_target_dependencies(turtle_control rclcpp geometry_msgs turtlesim)

install(TARGETS turtle_circle turtle_control
        DESTINATION lib/${PROJECT_NAME})
```

**坑点：**

- **`find_package` 和 `ament_target_dependencies` 两处都要写**。只写 `find_package`，编译时报"找不到头文件"；只写 `ament_target_dependencies`，CMake 报找不到包。
- **`package.xml` 里也要加 `<depend>`**（`geometry_msgs`、`turtlesim`），否则跨机部署时依赖不完整。
- **`install(TARGETS ...)` 里漏掉可执行文件**，`ros2 run` 就报 `No executable found`。
- 本机环境已验证：Ubuntu 24.04 + **ROS 2 Jazzy** 下 `ament_target_dependencies` 可用，教材写法不用改。

## 7. 调试话题的常用命令

这是**排查"为什么没反应"**的主力工具：

```bash
ros2 topic list                    # 列出所有话题，先确认话题名拼对了
ros2 topic info /turtle1/cmd_vel   # 看类型、有几个发布者/订阅者
ros2 topic echo /turtle1/pose      # 打印话题内容（最常用，验证有没有数据在流）
ros2 topic hz /turtle1/pose        # 看发布频率
ros2 topic pub /turtle1/cmd_vel geometry_msgs/msg/Twist \
    "{linear: {x: 1.0}, angular: {z: 0.5}}"    # 手动发一条，不用写代码
ros2 interface show geometry_msgs/msg/Twist    # 查消息类型的字段定义
```

**排查顺序**：`ros2 topic list` 里有没有这个话题 → `ros2 topic info` 的发布/订阅数对不对 → `ros2 topic echo` 有没有数据 → 最后才怀疑自己的代码。

## 8. 记忆要点

- 话题 = **发布者发、订阅者收、异步不等回复**；话题名和消息类型两边必须一致
- 发布者：`create_publisher<类型>("话题", 队列长度)` + 定时器 + `publish(msg)`
- 订阅者：`create_subscription<类型>("话题", 队列长度, std::bind(&类::回调, this, _1))`
- 回调参数是 `消息::SharedPtr`，字段用 `->`；少了 `this` 或 `spin()` 代码就是"哑巴"
- 没有 `rclcpp::spin(node)`，**所有回调都不会执行**
- 闭环模板：**订阅位置 → 算距离/角度 → 比例控制算速度 → 发布速度**，`atan2` 求方位、`fabs` 判阈值、限速截断
- CMake 里 `find_package`、`ament_target_dependencies`、`install(TARGETS ...)` 三样缺一不可，且都要和 `package.xml` 的 `<depend>` 对上
- 调试先跑 `ros2 topic list / info / echo`，别急着改代码
